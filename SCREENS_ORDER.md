# Kutoot App – Final Screens in User Flow Order

All screens are implemented and ordered from the user's perspective.

---

## 1. Pre-Auth Flow

| Order | Screen | Path / Entry |
|-------|--------|--------------|
| 1 | Splash | App launch |
| 2 | Onboarding (4 slides) | First launch only |
| 3 | Location Permission | After onboarding |
| 4 | Sign Up | Google / Apple / Phone |
| 5 | Login | Phone number |
| 6 | OTP Verification | After login |
